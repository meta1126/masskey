## プロジェクト概要

**Tauri + SvelteKit + TypeScript** のデスクトップアプリです。Mastodon のログイン機能を実装しているようです。

#### ディレクトリ構成

```
masskey/
├── src/                  # フロントエンド (SvelteKit)
│   ├── app.html          # HTML テンプレート
│   ├── lib/              # 共有モジュール
│   └── routes/           # ルーティング (+page.svelte, +layout.ts)
├── src-tauri/            # バックエンド (Rust/Tauri)
│   ├── src/
│   │   ├── main.rs       # Rust 側エントリポイント
│   │   ├── lib.rs        # Tauri コマンド定義 (Mastodon 認証ロジック)
│   │   └── api/          # API モジュール
│   ├── tauri.conf.json   # Tauri 設定
│   └── Cargo.toml        # Rust 依存関係
├── static/               # 静的ファイル
├── package.json          # Node.js 依存関係
├── svelte.config.js      # SvelteKit 設定 (SPA モード)
└── vite.config.js        # Vite 設定 (ポート 1420)
```

#### エントリポイント

| 層 | ファイル | 役割 |
|---|---|---|
| **アプリ起動** | `src-tauri/src/main.rs` | Rust 側エントリ。`masskey_lib::run()` を呼ぶ |
| **Tauri 初期化** | `src-tauri/src/lib.rs` | Tauri Builder、コマンド登録 (`start_login`, `complete_login`)、AppState 管理 |
| **HTML テンプレート** | `src/app.html` | SvelteKit アプリのルート HTML |
| **画面ルーティング** | `src/routes/+page.svelte` | メイン画面 (トップページ) |

つまり、**実行の流れ**は：

```
src-tauri/src/main.rs
  → src-tauri/src/lib.rs (Tauri 初期化 + コマンド定義)
    → src/app.html (HTML 描画)
      → src/routes/+page.svelte (UI 表示)
```

になります。
