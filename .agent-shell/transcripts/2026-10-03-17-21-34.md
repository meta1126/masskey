##### 技術スタック

| 層 | 技術 |
|---|---|
| フレームワーク | **Tauri v2** (Rust) + **SvelteKit v2** (Svelte 5) |
| バンドラ | **Vite** |
| 言語 | フロント: TypeScript / Svelte, バック: Rust |
| パッケージ管理 | Frontend: `bun.lock`, Backend: `Cargo.lock` |

##### 主な依存関係

- **Frontend**: `@tauri-apps/api`, `@tauri-apps/plugin-opener`, `@tauri-apps/plugin-shell`
- **Backend (Rust)**: `tauri v2`, `mastodon-async v1` (Mastodon OAuth 用), `tokio`, `serde`

##### 現在の機能

- `start_login`: Mastodon インスタンス URL を受け取り、OAuth 認可 URL を生成してブラウザで開く
- `complete_login`: 認可コードを受け取り、アクセストークンを取得して `Account` オブジェクトを返す
- 認可フローは `urn:ietf:wg:oauth:2.0:oob` (Out-of-Band) 方式

非常に初期段階のプロトタイプです。`Login.svelte` の中に `+page.svelte` のテンプレートコードが混在しているなど、整理が必要な箇所があります。
